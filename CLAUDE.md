# Ranobe Translator — правила проєкту

## Мова
- Спілкування зі мною: українською. Код, коментарі, коміти: англійською.

## Принципи коду
- Простий, читабельний код. Ясність краще за хитрість.
- Шарова архітектура: `core/` (логіка, без UI) → `services/` → `ui/`. Core ніколи не імпортує UI.
- Нові провайдери, експортери, мови додаються через реєстр/інтерфейс, без правок існуючого коду.
- Type hints скрізь, dataclasses/pydantic для моделей даних.
- Жодних секретів у коді, логах чи git.
- Усі UI-рядки тільки через i18n (uk, en). Жодного хардкоду тексту в UI.

## Робочий процес
- Перед великою зміною: короткий план, чекати мого підтвердження.
- Кожна фаза: тести (pytest) → ruff → коміт з описом.
- Нестабільні API (LLM) у тестах мокаються.
- Документація: ARCHITECTURE.md і ROADMAP.md оновлюються після кожної фази.

## Команди
- Тести: `pytest -q`
- Лінт: `ruff check . --fix && ruff format .`
- Застосунок: `python -m ranobe` (потрібен `pip install -e .[ui]`), у браузері: `python -m ranobe --web`
- Ядро без UI: `python -m ranobe.cli --help`
