# Правила перекладу ранобе на українську

Цей skill має два призначення:
1. **Для коду додатку.** Коли пишеш системні промти, JSON-схеми відповідей LLM, логіку редактора чи глосарію, спирайся на правила нижче. Вони мають бути вбудовані в промти додатку, а не лише в цей файл.
2. **Для перевірки якості.** Коли тестуєш переклад або пишеш тестові фікстури, оцінюй результат за чеклістом у кінці.

Правила за замовчуванням можна перевизначити: глосарій твору → налаштування твору → глобальні налаштування → цей файл (від найвищого пріоритету до найнижчого).

---

## 1. Базові принципи

- **Сенс і голос важливіші за буквальність.** Переклад має читатися як написаний українською, а не як калька.
- **Зберігати стиль автора:** короткі рубані речення лишаються короткими, внутрішній монолог лишається монологом, комічне лишається комічним.
- **Кожен персонаж говорить своїм голосом.** Манера мовлення (грубість, ввічливість, дитячість, архаїчність) зберігається протягом усього твору.
- **Послідовність понад усе.** Імена, терміни, назви технік, рангів і локацій беруться з глосарію. Новий термін пропонується до глосарію, а не вигадується щоразу заново.
- **Нічого не додавати й не викидати мовчки.** Якщо щось втрачається при перекладі, це фіксується приміткою (розділ 6). Якщо є кілька рівноцінних варіантів, це спірний момент (розділ 7).

## 2. Норми української мови

- Лапки: «ялинки», внутрішні — „лапки“.
- Діалоги: через тире (—), а не дефіс. Пряма мова з авторськими словами: `— Іди сюди, — сказав він.`
- Три крапки одним символом: `…`
- Уникати русизмів і кальок: «приймати участь» → «брати участь», «на протязі» → «протягом», «слідуючий» → «наступний», «співпадати» → «збігатися», «вірно» (у значенні «правильно») → «правильно».
- Менше пасиву й віддієслівних іменників: «ним було прийнято рішення» → «він вирішив».
- Кличний відмінок для звертань, де це природно: «Андрію», «пане Сато». Японські імена на -о/-а відмінювати обережно, за усталеною практикою (Харуко → Харуко, незмінне; Юка → Юко, Юці — тільки якщо послідовно в усьому творі; за замовчуванням не відмінювати жіночі імена на -о, відмінювати на -а).
- Числа в художньому тексті словами, якщо вони короткі («три дні»), цифрами — великі значення, характеристики, статистика (у системних вікнах LitRPG).
- Фемінітиви природні для сучасної української: «магиня», «лицарка», «авантюристка».

## 3. Імена та транслітерація

За замовчуванням (якщо в глосарії нічого немає):

**Японська → українська (система Коваленка):**
- し → сі, ち → ті, つ → цу, じ/ぢ → дзі, ず/づ → дзу, ふ → фу
- しゃ → ся, ちゃ → тя, じゃ → дзя
- や/ゆ/よ → я/ю/йо, え → е (на початку слова й після голосних теж е), ん → н (перед п/б/м — м за бажанням, але послідовно)
- Довгі голосні не позначаються: Сато, Токіо, Рюдзі.

**Китайська → українська:** за усталеною українською практикою (zh → чж, ch → ч, sh → ш, x → с, q → ц, j → цз, r → ж, -ng → -н): Сяо Янь, Лін Фен, Чжан Сань. Назви сект і технік — перекладати за змістом, якщо назва має смисл («Секта Небесного Меча»), а транслітерацію оригіналу давати в примітці при першій появі.

**Корейська → українська:** за практичною транскрипцією (ㅓ → о, ㅡ → и, ㅢ → ий, 이 → і): Кім Докча, Лі Хьон, Пак Чін'у.

**З англійської (як мова-посередник):** якщо твір перекладено з японської/китайської через англійську, відновлювати оригінальну форму імені, а не транслітерувати англійське написання (Shou → Шьо, а не «Шоу»). Якщо оригінал невідомий, позначити в глосарії `uncertain: true`.

## 4. Японські суфікси й звертання

Режим задається в налаштуваннях твору:

- **`keep` (за замовчуванням для ранобе):** суфікси зберігаються через дефіс: Сато-сан, Юкі-тян, Танака-сенпай, Ямада-сенсей. При першій появі кожного суфікса додається примітка типу `cultural`.
- **`adapt`:** суфікси передаються засобами української: -сан → «пан/пані» або просто ім'я на «ви»; -тян → зменшувальна форма («Юкочка»), -сама → «пане/пані» чи «володарю/владичице», -сенпай → «старший», сенсей → «вчителю».
- **`drop`:** суфікси прибираються, ввічливість передається через «ти/ви» й лексику.

Незалежно від режиму:
- Зміна суфікса (наприклад, з -сан на -кун чи на ім'я без суфікса) часто є сюжетним моментом. Її не можна згладжувати; у режимах `adapt`/`drop` додавати примітку.
- Кейґо (ввічливе мовлення) → «ви», нейтрально-формальна лексика. Грубе мовлення (оре, теме, кісама) → «ти», розмовна, різка лексика, без матів, якщо рівень цензури не дозволяє (розділ 8).
- Займенники першої особи (ватасі/боку/оре/васі) в українській не розрізняються. Якщо вибір займенника характеризує персонажа (дівчина говорить «боку», старий — «васі»), передати це манерою мовлення, а при першій появі додати примітку.

## 5. Ономатопея, ігри слів, діалекти

- **Ономатопея:** перекладати українськими звуконаслідуваннями або описово («Ґіґі…» → «Скрип…», «доки-доки» → «серце калатало»). Не транслітерувати, якщо в оригіналі це не стилістичний прийом. У СФХ-подібних вставках можна лишити транслітерацію з приміткою.
- **Ігри слів, каламбури, гра на кандзі:** спочатку шукати український еквівалент, що зберігає жарт. Якщо не вдалося — дослівно + примітка типу `wordplay` з поясненням оригінальної гри.
- **Діалекти** (кансайський, сільський, архаїчний): не підміняти конкретним українським діалектом (гуцульським, суржиком тощо), бо це додає чужих асоціацій. Передавати колоритною розмовною мовою, характерними словечками; при першій появі — примітка.
- **Архаїчна мова** (старий самурай, давній дракон): легка архаїзація української («мовлю», «зволь», «доки»), без перебору.

## 6. Примітки (тлумачення та коментарі)

Додавати примітку, коли:
- щось неможливо перекласти без втрати сенсу (гра слів, культурне значення імені, подвійне значення);
- згадується локальна реалія (свята, їжа, школа, ієрархії, міфологія, історичні події);
- вузькоспеціалізований термін (культивація, LitRPG-системи, військові, медичні терміни);
- зроблено свідомий вибір адаптації, який читач має знати (змінено суфікс, адаптовано жарт).

НЕ додавати примітки до очевидного з контексту та до кожного повтору (лише перша поява в творі; повтори — посилання на глосарій).

Типи: `untranslatable` · `wordplay` · `cultural` · `term` · `reference` (відсилка до іншого твору, аніме, мему) · `translator_choice`.

Формат, який LLM повертає для примітки:

```json
{
  "type": "cultural",
  "anchor": "Обон",
  "source_fragment": "お盆",
  "text": "Обон — японське буддійське свято вшанування предків у серпні. Люди повертаються в рідні місця, запалюють ліхтарі для духів.",
  "first_occurrence": true
}
```

Текст примітки: коротко (1–3 речення), нейтрально, українською, без спойлерів наступних розділів.

## 7. Спірні моменти

Спірний момент — коли є **кілька обґрунтованих варіантів** і вибір залежить від смаку чи ширшого контексту, якого модель не бачить. Не позначати як спірне те, що є очевидною помилкою або має один правильний переклад.

Типові випадки:
- двозначність в оригіналі (займенник без чіткого референта, пропущений суб'єкт у японській);
- назви технік, рангів, локацій без усталеного перекладу;
- переклад vs транслітерація;
- рівень формальності між персонажами;
- жарт, який можна адаптувати по-різному.

Формат:

```json
{
  "segment_id": "ch12-p34",
  "source_fragment": "剣聖",
  "issue": "Титул не має усталеного українського відповідника",
  "options": [
    {"text": "Святий Меча", "rationale": "Дослівно, зберігає пафос оригіналу"},
    {"text": "Майстер Меча", "rationale": "Звичніше для українського фентезі, але втрачає «святість»"},
    {"text": "Кенсей", "rationale": "Транслітерація; потребує примітки"}
  ],
  "recommended": 0,
  "add_to_glossary": true
}
```

Вимоги: 2–4 варіанти, кожен з коротким обґрунтуванням; `recommended` — індекс варіанта, який модель вважає найкращим (він стоїть у тексті до рішення користувача); якщо рішення стосується терміна, `add_to_glossary: true`, щоб вибір користувача автоматично потрапив у глосарій і застосувався надалі.

Ліміт: не більше ~5 спірних моментів на чанк. Якщо їх більше, показати найважливіші, решту вирішити за рекомендацією.

## 8. Рівні цензури

Рівень задається в налаштуваннях твору й вбудовується в промт перекладу та редагування.

| Рівень | Лайка | Насильство | Відверті сцени |
|---|---|---|---|
| `original` | Передається з відповідною силою | Як в оригіналі | Як в оригіналі в межах політик моделі |
| `softened` | Пом'якшується («чорт», «дідько») | Без натуралістичних подробиць | Описово, без деталей |
| `family` | Прибирається або замінюється | Мінімально, без описів ран | Затемнення сцени («двері зачинилися») |

Правила:
- Рівень змінює **подачу**, а не сюжет. Події лишаються тими самими; читач має розуміти, що сталося.
- При пом'якшенні в `softened`/`family` значні фрагменти не викидаються мовчки: редактор позначає сегмент прапорцем `censored: true`, щоб користувач бачив, де текст змінено.
- Моделі мають власні обмеження вмісту. Якщо модель відмовилася перекладати фрагмент або явно спотворила його, додаток має це виявити (порожня відповідь, відмова, різке скорочення довжини) і позначити сегмент для ручної перевірки, а не підставляти результат мовчки.

## 9. Структура промтів у додатку

Системний промт перекладу збирається з блоків (у такому порядку):
1. Роль і мета (перекладач художньої літератури, мова-джерело → українська).
2. Правила з цього файлу, стисло (розділи 1–5, відповідно до налаштувань твору).
3. Налаштування твору: режим суфіксів, рівень цензури, стиль.
4. Глосарій — лише терміни, що трапляються в поточному чанку (не весь глосарій, щоб економити контекст).
5. Контекст: коротке резюме сюжету до цього моменту + кінець попереднього чанка (оригінал і переклад).
6. Формат відповіді: JSON з полями `translation`, `notes[]`, `disputes[]`, `glossary_suggestions[]`.

Другий прохід (редагування) отримує оригінал і чорновий переклад і перевіряє за чеклістом нижче, повертаючи виправлений текст і список змін.

Відповіді LLM завжди валідувати за схемою. При невалідному JSON — одна повторна спроба з повідомленням про помилку, далі — сегмент позначається для ручної перевірки.

## 10. Чекліст перевірки якості

- [ ] Сенс збережено, нічого не пропущено й не додано
- [ ] Імена й терміни відповідають глосарію
- [ ] Суфікси за обраним режимом, зміни суфіксів не згладжені
- [ ] Голос кожного персонажа послідовний
- [ ] Немає русизмів, кальок, зайвого пасиву
- [ ] Типографіка: «лапки», тире в діалогах, `…`
- [ ] Ігри слів і реалії або адаптовані, або мають примітку
- [ ] Примітки лише при першій появі, короткі, без спойлерів
- [ ] Рівень цензури дотримано, змінені фрагменти позначені
- [ ] Текст читається природно вголос
